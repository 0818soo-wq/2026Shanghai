# 2026 SHANGHAI (2nd)

단일 HTML 파일로 만든 모바일용 여행 일정표입니다. 서버 없이 브라우저에서 바로 열립니다.

🔗 https://0818soo-wq.github.io/2026Shanghai/

## 구성
- **일정 탭**: 11.7~11.10 일자별 카드 (날씨/옷차림, 숙소, 교통편, "오늘 뭐 먹지?" 버튼)
- **동선 탭**: 인천 ↔ 상하이(푸동) 항공 경로 + 일자별 동선
- **식사 탭**: 4일치 아침/점심/저녁을 한 페이지에서 카드로 확인
- **비용 탭**: 항목별 지출완료(파란)/지출예정(빨간) 색상 구분
- **예약사항 탭**: 항공/숙소/공항 픽업 일정 정리

## 오프라인 지원
`sw.js` 서비스워커가 한 번이라도 온라인으로 연 페이지를 캐시해둡니다.
비행기 안이나 통신이 끊긴 구간에서도 일정 확인이 가능합니다.
내용을 고친 뒤에는 캐시 갱신을 위해 `sw.js`의 `CACHE` 버전을 올려야 합니다.

## 지도
중국 본토에서는 Google 지도가 정상 동작하지 않아, 모든 위치 링크는
고덕지도(Amap, `uri.amap.com`)로 연결됩니다.

> 이 저장소는 Public이며, 예약번호·좌석 정보·탑승객 실명·숙소 상세 주소가 포함되어 있습니다.
> 예약번호는 앞 3~4자리만 공개합니다. 링크를 아는 사람은 누구나 볼 수 있으니 외부에 공유하지 마세요.

## 배포
GitHub Pages로 자동 배포됩니다 (main 브랜치 / root). 저장소 Settings → Pages → Source를
"Deploy from a branch" / `main` / `/(root)`로 설정해야 합니다.
